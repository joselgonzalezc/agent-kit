# Pitfalls

Things that have bitten agents and humans on this project and are not obvious from the code.
Read by every agent before working. One entry per trap; keep each under ~6 lines.

Add an entry when a mistake cost real time and could happen again. Remove it when the trap is
engineered away (a script, a guard, a lint rule) — then record the fix in the decisions log.
