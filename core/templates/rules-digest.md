# Rules digest

One line per constitution rule, same ids. Agents read this instead of the full constitution and
open a full section (search its heading) only when the line is not enough.

Regenerate or edit it in the same change as any constitution amendment — a digest that disagrees
with the constitution is a defect; the constitution wins.

Format: `<id> [!] <rule in ≤ 20 words>` — `[!]` marks NON-NEGOTIABLE.
